02 / Operational scopeEach prerequisite retains its issuer and evidence

Fleet, country conditions
and shared resources.

Operational authorisation, site and airspace access, U-space authorisation, internal readiness, pilot acknowledgement and actual execution remain distinct decisions.

A / Fleet

Maintenance follows the aircraft baseline.

Configuration, measured utilisation, approved programme intervals and completed work feed deterministic readiness checks. A capacity planner assigns work orders against technicians, facilities and aircraft availability.

A planned task or completed work order does not create a maintenance release. Qualifications, source instructions and independent review remain explicit.

B / Europe

Cross-border readiness is built by segment.

Record the registration state, operating countries, local conditions, legal route, applicable instruments and handovers. Authorisation, declaration and LUC routes preserve their different requirements.

A country in the registry is not a validated national pack. Luxembourg and Italy require qualified review; UK applicability is separate.

C / Shared resources

Consent and physical availability are checked together.

Owner and operator retain separate identities and responsibilities. Scoped sharing agreements and the physical aircraft ledger support checks for conflicting reservations and readiness limits.

Sharing consent does not supply an operating permission. Internal checks do not activate a provider or an aircraft.

03 / Agent architectureSystem Labs multiagentic systems ↗

Local LLM orchestration.
Explicit specialist contracts.

The controller generates a proposed next tool. The server admits it against scope, role, dependencies and budget, then records the tool’s actual result before the next step.

Neural computation

Qwen3-1.7B generates structured proposals locally. Pretrained embeddings and a cross-encoder perform source retrieval and ranking. The earlier student remains an optional, unpromoted signal.

Deterministic authority

Typed admission, source/date filters, operational rules, optimisation, independent verification and approval gates operate outside the language model.

Shared System Lab core

The new systemlab_agentic package supplies reusable task, scope, capability, receipt, wait and reconciliation contracts. Airspace and a document-research adapter consume the same core.

This is a new cross-domain implementation aligned with the existing System Labs programme. It does not copy proprietary SPINS/trading assets or claim wire compatibility with trading-specific commands. Inspect the implementation mapping ↗

Owned presentation runtime. The application also integrates five byte-identical distributed System Lab resources for its 2.5D WebGL companions. The new adapter reflects workflow state and supports reduced motion, pause and a static-image fallback. This is presentation technology, separate from neural inference and operational authority. The software prepares evidence, checks inputs and proposes work. It is not an autopilot, certified Detect and Avoid system, separation service, air traffic control system, competent authority or U-space provider.
