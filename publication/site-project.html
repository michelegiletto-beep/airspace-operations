Working scope

The application connects versioned authorisation cases, genuine evidence records, reviewer permissions, a source library, spatial and risk checks, scheduling, fleet/personnel records, read-only telemetry imports, incident workspaces and conditional deployment economics. A pristine operational workspace is empty.

Architecture and installation

React and TypeScript interface; modular Python/FastAPI services; persistent records, leased jobs, a transactional outbox and content-addressed evidence storage. SQLite is the verified local portability profile. PostgreSQL/PostGIS/pgvector container deployment is prepared and requires execution/acceptance testing.

The download contains hash-locked dependencies, migrations, OpenAPI and calculation contracts, container files, handbooks, recovery procedures, source manifests, model/dataset cards, tests, capability status, SBOM and release provenance. The core remains usable without System Lab hosting or a hosted model subscription.

Experimental neural artifact

A real 12,386-parameter student was trained to route literal shall-language passages for review, using machine annotations of real source text. On 77 held-out machine-labelled passages it achieved 81.82% agreement, below the deterministic baseline. It remains experimental and unpromoted. This is not a legal-obligation model or evidence of operational reliability.

Operational acceptance remains separate

This is decision-support software. It is not an autopilot, certified separation/DAA service, competent authority, air traffic control system or U-space provider. Software tests do not approve flights. Deployment requires lawful data access, qualified review, operator procedures, security configuration, real integration/acceptance tests and applicable permissions.

Full methodology coverage, deeply validated national packs, live provider integration, production dispatch, automatic retention/erasure and other documented capabilities remain incomplete. No customer, flight history, telemetry, approval or commercial result has been fabricated.
