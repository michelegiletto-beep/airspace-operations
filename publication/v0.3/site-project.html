System Lab Airspace Operations

Software for planning and reviewing civilian drone operations.

The application keeps intended missions, evidence, aircraft, people and tasks in one place. It runs on your own computer or server with a persistent database and background workers.

Work in the application

  • Describe the mission you intend to carry out.
  • Add real aircraft, people, places and supporting documents.
  • See what information and review are still missing.
  • Prepare resource plans and keep review decisions traceable.
  • Keep incidents, actions and records with their evidence.

A new operational workspace is empty. Proposed missions do not record actual flights, and an internal review does not create an authority permission.

What is changing

This revision is being prepared to give less experienced users clearer instructions and local model assistance. It is intended to save conversations and tasks, explain next steps and show proposed internal actions before the user confirms them.

The existing owned companion is being updated to move during normal use, including when a fallback renderer is needed. The background will respond quietly to interaction. Pause and reduced-motion preferences remain available. These changes are pending the new candidate's actual execution and browser checks.

Evidence

The released 0.2 candidate has recorded container, database, worker, model and installation checks. Those results describe that release. New code requires new evidence.

The experimental student model and annotation dataset remain unchanged. The public evidence viewer performs no live inference and is separate from an authenticated operational deployment.

Before operational use

The software supports preparation and review. It does not command aircraft, provide certified separation or grant permission to fly. National validation, real operator records, lawful feeds, approved procedures and accountable review remain necessary.

The original specification is not fully accepted. The country catalogue does not establish validated national coverage, and no live provider connection is implied.
