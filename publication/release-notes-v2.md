System Lab Airspace Operations 0.2 adds actual local LLM orchestration and integrated maintenance, shared-fleet and European coordination workflows to the installable operations platform.

![Actual Mission Control workspace](https://raw.githubusercontent.com/michelegiletto-beep/airspace-operations/3d5376758493f8e791dce85968947878990c6b6f/publication/media/mission-control.jpg)

The application now combines a reusable System Lab coordination core, a local Qwen3-1.7B controller, pretrained retrieval/reranking, an optional experimental trained student, typed tools and deterministic admission/review gates. The interface integrates the owner's actual animated companion presentation runtime with separate reserved rights.

Maintenance programmes, source revisions, work completion, independent release, technician/facility scheduling, country segments, STS/LUC host provision, bilateral sharing, global physical-aircraft reservations, pilot acknowledgement and internal dispatch retain separate evidence and authority boundaries.

**Engineering candidate — full original specification and operational acceptance remain incomplete.** National packs require qualified review. No accepted live operational feed or U-space provider is connected. Full SORA, recurrence/charging, interactive offline operation and production-scale assurance remain documented gaps. No software state approves a flight or provides certified Detect and Avoid/separation.

Verified locally: 267 Python tests passed with 16 PostgreSQL skips; 69 interface tests and the production build passed. [Actual container CI](https://github.com/michelegiletto-beep/airspace-operations/actions/runs/40683325217) passed health, a job completed by the running worker/API, 16 PostgreSQL/PostGIS/vector/concurrency tests and pg_dump/pg_restore. The exact downloadable archive has its own attached installation/test evidence; skipped upstream originals and environments are explicit. Dependency and publication-tool scans, SBOM format validation, earlier failures and current limitations are preserved.

The actual five-step controller workflows and four small native/causal trials are inspectable in the [recorded evaluation Space](https://huggingface.co/spaces/Magic51/system-lab-airspace-evaluation). This Space performs no inference and is not the operations platform. Existing student weights and dataset are unchanged and remain experimental; no new training or performance advantage is claimed.
