# Security reporting

Do not include credentials, personal data, private correspondence or operational evidence in public issues. If a verified public repository enables private vulnerability reporting, use that channel. Otherwise contact the deploying organisation's designated security owner through its approved private channel. No unverified email address is supplied by this release.

Retain affected software version, minimal isolated reproduction, tenant-boundary impact and non-sensitive request IDs. Do not test production aircraft or authority systems. Critical tenant isolation, approval bypass, fabricated-data or exposed-secret findings block release until repaired and reverified. Disclose fixes with factual scope and executed verification.
