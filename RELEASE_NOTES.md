# 0.1.0-rc.1

Engineering candidate with a real Python API, persistent local database, separately runnable worker/inference service and typed React interface. Implements tenant isolation, role controls, independent review, revision history, evidence integrity, controlled JSON/HTML exports, HMAC audit verification and restoration mechanisms. Operational workspaces install empty.

Adds actual primary-source ingestion, structured table/paragraph anchors, jurisdiction/date/status/tenant filtering, local pretrained retrieval and reranking, version-specific SORA evidence/limited source-bound calculations, geodesic site screening, fleet/personnel records, CP-SAT scheduling with separate verification, transaction-safe internal resource reservation/cancellation, read-only telemetry import, alert acknowledgement, approved-procedure incident workspace, degraded snapshot export and explicit-input economics.

Includes completed local teacher/student experiments and an experimental12,386-parameter student. Its task is literal shall-language reviewer routing; it underperforms the deterministic baseline and is not promoted. No operational prediction model was trained. Historical training versions and subsequent patched inference environment are recorded separately.

Release hardening repaired revision self-approval, user-editable second-review policy, resource/receipt staleness, cross-schedule battery/duty/capacity and duplicate-mission conflicts, orphaned exhausted job leases, tool-role mismatch, oversized chunked requests, forged attachment metadata and a vulnerable solver dependency chain. Actual commands, coverage, findings, cold/warm model measurements and source coverage are in release-evidence/ and docs/.

Full original-specification acceptance, PostgreSQL/container verification, deeply validated national packs, full SORA, live provider acceptance, complete dispatch and real-world deployment remain blocked as described in docs/known-limitations.md. No flight approval, certification or production readiness is conferred by this release.
