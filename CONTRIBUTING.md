# Contributing

Read AGENTS.md, SPECIFICATION.md and SAFETY_BOUNDARY.md. Add requirement IDs, meaningful tests and executed evidence for changes. Never seed artificial operational data outside isolated tests. Keep legal sources and methodology editions anchored and versioned. Dependency, dataset, model and source-document licences remain separate. New connectors require permitted-purpose review and actual integration evidence before being marked Connected.

Run the Python and frontend suites and release verification. Use independent reference calculations for operational rules; do not mirror solver implementation in tests. Record security/domain review findings and fix critical gates before publication. A trained candidate remains experimental until a qualified accountable promotion and rollback decision is recorded.
